# latex-tabalhos

Caso queira o corretor de texto, use a extensão `Code Spell Checker`.

Instalar dependencias para uso(ubuntu):
```
sudo apt install texlive-full
sudo apt install latexmk
sudo apt install chktex texlive-extra-utils
# Minimo
sudo apt install texlive-latex-recommended texlive-latex-extra texlive-fonts-recommended
sudo apt install latexmk
sudo apt install chktex texlive-extra-utils
```
